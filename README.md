# Stock Analysis Skill

面向 A 股、港股和美股的上市公司研究与估值学习技能。流程是：

1. 公司怎么赚钱。
2. 行业发生什么变化。
3. 变化如何体现在财务。
4. 市场价格隐含什么预期。

技能保留商业模式、财务排雷、盈利质量、PE/PS、倒推市值、关键因子、反证和风险，但不输出强制买卖、仓位、止盈止损或星级评分。

## 数据原则

- A 股优先 SSE/SZSE 公告，公司 IR；AkShare、东方财富用于辅助。
- 港股优先 HKEX 披露易和公司 IR。
- 美股优先 SEC 10-K、10-Q、8-K 和公司 IR。
- 每个关键数记录来源、报告期、披露日期、单位、币种和会计口径。
- 港美公司没有 A 股同口径的扣非利润或销售收现时写 `N/A`。
- 事实、假设和推论分开；红旗是核验线索，不是造假证明。
