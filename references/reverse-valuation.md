# 倒推市值与隐含预期

## 目的

倒推估值用于回答“当前市值需要怎样的收入、利润率或增长路径才说得通”，不是给出确定目标价，也不能把假设的全年目标偷换成下一季度必须完成的最低业绩。

## 基础公式

| 项目 | 公式与边界 |
|---|---|
| 总市值 | 估值日股价 × 对应股份口径；ADR/ADS 先换算 |
| TTM 收入/利润 | 最近四个可比单季之和，或最近年报 + 最新 YTD − 上年同期 YTD |
| PE | 总市值 ÷ TTM 或假设的全年归属利润；利润≤0 或经济含义不足时为 `N/M` |
| PS | 总市值 ÷ TTM 或假设的全年收入 |
| 最近单季收入年化 PS | 总市值 ÷（最近单季收入 × 4） |
| 隐含全年利润 | 总市值 ÷ 假设 PE |
| 隐含全年收入 | 总市值 ÷ 假设 PS |
| 隐含利润率 | 隐含全年利润 ÷ 隐含全年收入 |

“最近单季收入 × 4”只是简单年化，必须紧邻说明季节性、季度天数、并购、汇率与一次性变化可能使它失真。禁止写成“总市值 ÷ 最近单季收入 × 4”；那会把年化方向写反。

## M/PE 的正确解释

`M/PE` 或“市值 ÷ 假设 PE”只得到一个**假设的全年利润目标**。若已披露部分年度利润为 `YTD`，剩余期间利润为：

`隐含剩余期间利润 = 隐含全年利润 − 已披露 YTD 利润`

这仍不是“下一季度最低业绩”。只有在明确假设剩余利润如何分配后，才能估计某季度值。例如把全年利润的 50% 分配给下半年，必须写成“季节分配假设：H2 占全年 50%”，并用历史季节性或业务理由说明。没有依据时只报告全年或剩余期间要求。

## 情景与敏感性

倍数、增长、利润率和季节分配不得使用写死的通用数字。建立至少两个由证据或清晰假设支持的情景，并展示结果对关键变量的敏感性：

| 情景 | 假设收入/增长 | 假设利润率 | 假设 PE 或 PS | 隐含结果 | 依据/反证 |
|---|---:|---:|---:|---:|---|
| 情景 A | | | | | |
| 情景 B | | | | | |

选择倍数时说明比较组、日期、盈利阶段、会计口径、增长与资本强度。任意 PE/PS 和“调整系数”都不能伪装成客观输入。

## 输出

把事实输入、假设参数和推论结果分表展示；明确哪些变化会支持或推翻当前隐含预期。亏损公司不计算无意义 PE。
