# 财务排雷与盈利质量

红旗是需要进一步解释和核验的线索，不是舞弊、造假或投资结论的证明。阈值因行业、商业模式、季节性与会计口径而异，不使用一套固定比例给所有公司判定。

## 核心检查

| 主题 | 可观察项目 | 追问 |
|---|---|---|
| 利润转现金 | 经营现金流/净利润、多期累计转换 | 差异来自营运资本、税、利息、预付款还是一次性事项？ |
| 收入质量 | 应收、合同资产、递延收入/合同负债、坏账 | 增长是否依赖更宽松信用；确认政策是否变化？ |
| 存货质量 | 存货增速、周转、跌价准备、渠道库存 | 是备货、价格波动、需求放缓还是产品迭代？ |
| 毛利与费用 | 毛利率、费用率、资本化项目 | 改善能否由价格、产品组合、成本或会计政策解释？ |
| 非经常项目 | 处置、补助、减值、投资收益、重组 | 对利润、现金和未来可持续性的贡献有多大？ |
| 资产负债 | 现金、受限资金、借款、租赁、担保 | “高现金+高债务”是否由用途限制、地域或期限解释？ |
| 股本变化 | 增发、回购、股权激励、可转债 | 每股指标是否被稀释；基本与稀释股数是否匹配？ |
| 关联方与审计 | 关联交易、审计意见、内控缺陷 | 定价、回款、持续经营或重大判断是否需要加深核验？ |

## 跨市场替代口径

- A 股可核对归母净利润、扣非归母净利润及销售商品、提供劳务收到的现金。
- 港股和美股若没有同口径“扣非”或“销售收现”，标 `N/A`。可改用经营利润、持续经营利润、经营现金流、自由现金流，或公司披露并可调节回 GAAP 的指标。
- 非 GAAP 指标必须列出与 GAAP 的调节项；不能只采用公司口径而省略股权激励、重组或摊销的影响。

## 写法

对每条红旗写四项：观察事实、可能解释、需要的验证材料、若解释不成立会影响哪项推论。避免“发现异常，因此造假”式跳跃。
