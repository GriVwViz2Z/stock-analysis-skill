# 数据源与口径

## 市场优先级

| 市场 | 一级来源 | 辅助来源 | 重要说明 |
|---|---|---|---|
| A 股 | 上交所 SSE、深交所 SZSE 的公司公告与定期报告；公司投资者关系页 | AkShare、东方财富等聚合数据 | 聚合数据只用于发现、初筛、计算和交叉核对；冲突时以交易所公告为准 |
| 港股 | 香港交易所 HKEX 披露易公告、年报/中报；公司 IR | 可信行情与数据服务 | 核对 HKFRS/IFRS、报告币种、股份类别和财政年；不要套用 A 股“扣非”口径 |
| 美股 | SEC EDGAR 的 10-K、10-Q、8-K 及其 exhibits；公司 IR | 可信行情与数据服务 | 核对 US GAAP、fiscal year、quarter 与 YTD；非 GAAP 指标必须回溯 reconciliation |

新闻、卖方报告、行业媒体和社交平台可提供线索或观点，但不能替代原始披露支撑关键财务或估值数字。

## 每条关键数据的最小记录

| 字段 | 要求 |
|---|---|
| 数据 | 数值、单位、币种、正负号 |
| 来源 | 文件/网页名称、发布主体、链接或页码 |
| 报告期 | 起止日期；年度、单季或 YTD |
| 披露日期 | 原始文件正式披露日期 |
| 访问日期 | 动态网页或聚合数据适用 |
| 口径 | GAAP/非 GAAP、归属口径、持续经营、是否经审计、股类/ADR 换算等 |
| 标签 | 事实 / 假设 / 推论 |

## 跨市场核对

1. **币种**：收入、利润、市值与倍数分母必须同币种；换汇写明汇率来源与日期。
2. **估值日期**：价格、总股本/稀释股数、净债务尽量对齐；不对齐时披露时间差。
3. **财政年**：不要把自然年标签强加给非自然年公司。
4. **季度与 YTD**：现金流量表常为累计口径。单季值若由累计值相减得到，标为“推算”。
5. **股份与 ADR**：核对基本/稀释股数、库存股、不同股类及每 ADS 代表多少普通股。
6. **会计口径**：中国会计准则、HKFRS/IFRS、US GAAP 和公司非 GAAP 指标不可无说明混用。
7. **缺失项**：美股或港股没有扣非净利润、销售收现等同口径披露时写 `N/A`，使用可核对的替代指标并解释差异。

## 冲突与缺口

- 原始披露之间存在重述时使用最新重述口径，并保留前值与原因。
- 第三方与正式披露冲突时，不默默选一个；列出差异、可能原因和采用值。
- 无法取得原文、页码或期间不明的数据，不得成为关键结论的唯一依据。
- 截止日之后发生的事件单列为“期后信息”，不得回填进截止日估值。
