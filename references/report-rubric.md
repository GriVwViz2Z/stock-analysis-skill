# 交付前自检

## 身份与口径

- [ ] 代码、交易所、法定名称、股类和分析截止日已确认。
- [ ] 报价币种、报表币种、财政年、季度/YTD、会计准则已说明。
- [ ] ADR/ADS 或多股类换算、基本/稀释股数口径已核对。

## 来源与期间

- [ ] 关键财务数据优先来自 SSE/SZSE、HKEX、SEC 或公司正式披露。
- [ ] 每个关键数有来源、报告期、披露日期、单位与口径。
- [ ] 动态价格/市值有估值日期；聚合数据没有覆盖正式披露。
- [ ] 事实、假设、推论已明确分开；缺失项标 `N/A` 或未知。

## 研究链

- [ ] 解释了公司怎么赚钱，而非只复述业务名称。
- [ ] 行业因子有传导链、财务落点和反证信号。
- [ ] 盈利质量覆盖现金、应收、存货与一次性项目，并考虑行业季节性。
- [ ] 红旗被表述为调查线索，不被直接当成造假证明。

## 估值

- [ ] PE/PS 分子分母同币种、同股份口径、期间匹配。
- [ ] 亏损或无经济含义的 PE 标为 `N/M`。
- [ ] 最近单季收入年化公式为 `总市值 ÷（最近单季收入 × 4）`，并提示季节性。
- [ ] `市值 ÷ 假设 PE` 只解释为假设全年利润；没有无依据地变成下季度最低业绩。
- [ ] 半年或季度分配比例均标为显式假设，并给出依据或不确定性。
- [ ] 倍数和调整参数有依据，不使用写死的通用数值。

## 输出边界

- [ ] 保留关键因子、反证和风险，不给强制买卖、仓位、止盈止损或星级。
- [ ] 历史演示未被当成当前事实；未经核验的数据不支撑当前结论。
